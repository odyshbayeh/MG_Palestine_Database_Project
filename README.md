# MG_Palestine_Database_Project

This project contains the source code, MySQL database files, and resources built with SceneBuilder for the MG Palestine Database.

## Project Overview

The MG_Palestine_Database_Project aims to provide a management system for Palestine-related data, integrating a backend MySQL database and a user interface developed with JavaFX and SceneBuilder. The repository includes:
- **Source Code**: Core application logic and functionality.
- **MySQL Scripts/Database**: Database schema and data required for the application.
- **SceneBuilder Files**: UI layouts and resources for the application's frontend.

## Features

- Database management using MySQL.
- Graphical User Interface (GUI) built with SceneBuilder.
- Modular structure with separate folders for source code and database assets.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/odyshbayeh/MG_Palestine_Database_Project.git
   ```
2. **Set up the Database:**
   - Import the provided MySQL scripts into your MySQL server.
   - Update database connection settings in the source code if needed.

3. **Run the Application:**
   - Open the project in your preferred IDE.
   - Make sure you have Java and JavaFX configured.
   - Build and run the application.

## Requirements

- Java (version as required by the code)
- MySQL Server
- SceneBuilder (for UI editing, optional)

## Repository Structure

- `/src` - Application source code
- `/mysql` or similar - Database scripts and data
- `/scenebuilder` or similar - UI layout files
